# RISCV Development Evironment

This repo is a bare-bones devcontainer for RISC-V development. It is based on the official RISC-V Docker image and includes additional tools and libraries for development.

The repo is setup to work with Visual Studio Code and the Dev Containers extension. It allows you to develop RISC-V applications in a containerized environment, which can be easily shared and reproduced.

## Features

- GCC for RISC-V
- Go 1.24.2
- RISC-V GNU Compiler Toolchain
- RISC-V GDB
- RISC-V QEMU

## Prerequisites

- Docker
